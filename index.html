Frequently asked questions

Clear expectations, no surprises.

How does downloading work?

The included backend can process supported public YouTube URLs. Run it on a server and only download content you own or are authorized to save.

Does the description generator use AI?

This demo creates a basic editable template locally in your browser. AI-quality generation would require an AI service/API connection.

Are my captions uploaded?

The copy and template tools run in your browser. This static page does not send your description or hashtags to a server.

Can I use it on a phone?

Yes, the layout adapts to smaller screens as well as desktop browsers.
